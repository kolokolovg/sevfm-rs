# sevfm (sevfm-rs)

[![CI](https://github.com/kolokolovg/sevfm-rs/actions/workflows/ci.yml/badge.svg)](https://github.com/kolokolovg/sevfm-rs/actions/workflows/ci.yml)

Настольный плеер онлайн-радио **«Говорит Севастополь»** на Rust + Slint.

Нативный бинарник с малым потреблением памяти и процессора
(десятки МБ RSS): без электрона, рантаймов и встроенных браузеров.

## Возможности

- **Живой стрим без разрывов.** Звук играет из буфера: при обрыве сети
  воспроизведение продолжается, соединение восстанавливается с нарастающей
  задержкой (1 → 2 → 5 → 10 с), мусор в потоке лечится переподключением.
- **Метаданные эфира (ICY).** Название станции и текущий трек; смена трека
  публикуется синхронно со звуком — когда звучит аудио, к которому относится
  метаблок, а не в момент его приёма. Рекламные вставки показываются
  названием без исполнителя. Сервер без ICY — чистый MP3 без строк эфира.
- **Окно-«Герой».** Крупная карточка обложки текущего трека, индикатор
  состояния, компактный фикс-кадр. Обложки ищет цепочка
  iTunes → Deezer → Яндекс с локальным кешом.
- **Трей и MPRIS.** Сворачивание в трей с меню, интеграция с аплетом
  KDE/GNOME: play/pause, статус, название трека.
- **Запуск:** `sevfm` — станция по умолчанию, `sevfm <URL>` — любой живой
  MP3-поток, `sevfm --headless` — без окна.

Остановка — Ctrl+C или SIGTERM: процесс завершается кодом 0 в течение
секунды. Фатальные ошибки старта (нет аудиоустройства, поток не распознан
как MP3) — код 2; сетевые сбои — переподключения, а не завершение.

Подробные спецификации поведения — в [openspec/specs](openspec/specs/).

## Сборка

Linux — сначала системные библиотеки (ALSA — вывод звука, xkbcommon и
fontconfig — окно):

```bash
sudo apt install libasound2-dev libxkbcommon-dev libxkbcommon-x11-dev libfontconfig1-dev
cargo build --release
```

Windows — `cargo build --release`; иконка exe вшивается ресурсом из
`packaging/sevfm.ico` автоматически.

## Установка

Готовые пакеты — на [странице релизов](https://github.com/kolokolovg/sevfm-rs/releases):

- **Linux (deb)** — `sevfm_<версия>_amd64.deb`: бинарник, `.desktop` и иконка
  (приложение «SevFM» появляется в меню с гербом). Релизный пакет собирается
  на Ubuntu 24.04 — нужен glibc ≥ 2.39; для более старых систем соберите
  локально: `cargo install cargo-deb && cargo deb`.
- **Windows** — `sevfm-<версия>-windows-x64.zip` с `sevfm.exe`.

Релизы выпускаются автоматически тегом `v*` (например, `v0.1.0`) — номер
тега обязан совпадать с версией в `Cargo.toml`. Каждый пуш и PR проверяет
CI: форматирование, линты, тесты (Linux) и сборку exe (Windows).

## Тесты

Обычный прогон сети не требует — серверные сценарии (обрывы, мусор,
не-MP3 ответы) обслуживает локальный мок-сервер:

```bash
cargo test
```

Живые тесты (реальный стрим и аудиоустройство) запускаются явно:

```bash
cargo test live_stream_reads_first_64k -- --ignored --nocapture
cargo test --test sigint_live -- --ignored
```

## Стек

Rust (edition 2024): `ureq` + rustls (HTTP/TLS) → `symphonia` (MP3-декодер)
→ `rodio`/`cpal` (вывод); Slint (окно, трей); `mpris-server` (D-Bus, Linux).

Заметка о cargo-прокси: если `static.crates.io` недоступен напрямую
(TLS до Fastly дропается провайдером), пропишите проксой локально
в `~/.cargo/config.toml` — в репозиторий конфиг не коммитится:

```toml
[http]
proxy = "http://127.0.0.1:10809"
```
