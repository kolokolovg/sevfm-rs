## [0.1.0] - 2026-11-02

Первый релиз: настольный плеер онлайн-радио «Говорит Севастополь».

### Added

- Воспроизведение живого MP3-стрима без разрывов: при обрыве сети звук
  продолжает играть из буфера, соединение восстанавливается с нарастающей
  задержкой (1 → 2 → 5 → 10 с), мусор в потоке лечится переподключением.
- Метаданные эфира (ICY): название станции и текущий трек; смена трека
  публикуется синхронно со звуком; сервер без ICY — чистый MP3.
- Окно-«Герой»: крупная обложка текущего трека, индикатор состояния,
  компактный фикс-кадр.
- Поиск обложек по исполнителю и названию: цепочка iTunes → Deezer → Яндекс
  с локальным кешом.
- Сворачивание в трей с меню и MPRIS: управление из аплета KDE/GNOME.
- Установочные пакеты: Windows — `sevfm.exe` в zip, Linux — deb с иконкой
  и ярлыком в меню приложений; автоматическая сборка и релизы через
  GitHub Actions.
