# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/), версионирование —
[SemVer](https://semver.org/lang/ru/).

## [0.1.2] - 2026-11-02

### Changed

- Память плеера сокращена примерно втрое: ~93 → ~32 МБ в покое и ~46 МБ
  при воспроизведении (замер PSS). Окно теперь рисуется программным
  рендерером вместо графического стека, который на части систем
  (Wayland + Intel) работал в медленном программном режиме и заодно
  тянул в память ~50 МБ системных библиотек компиляции графики.
  Вид и поведение окна не изменились.

## [0.1.1] - 2026-11-02

### Fixed

- Иконка на панели задач в Wayland-сессиях: окно не имело идентификатора
  приложения (app_id), из-за чего панель задач не находила приложение и
  показывала заглушку вместо герба. Идентификатор совпадает с именем
  ярлыка — теперь иконка есть и в меню, и у запущенного окна.

## [0.1.0] - 2026-11-02

Первый релиз: настольный плеер онлайн-радио «Говорит Севастополь».

### Added

- Воспроизведение живого MP3-стрима без разрывов: при обрыве сети звук
  продолжает играть из буфера, соединение восстанавливается с нарастающей
  задержкой (1 → 2 → 5 → 10 с), мусор в потоке лечится переподключением.
- Метаданные эфира (ICY): название станции и текущий трек; смена трека
  публикуется синхронно со звуком; сервер без ICY — чистый MP3.
- Окно-«Герой»: крупная обложка текущего трека, индикатор состояния,
  компактный фикс-кадр.
- Поиск обложек по исполнителю и названию: цепочка iTunes → Deezer → Яндекс
  с локальным кешом.
- Сворачивание в трей с меню и MPRIS: управление из аплета KDE/GNOME.
- Установочные пакеты: Windows — `sevfm.exe` в zip, Linux — deb с иконкой
  и ярлыком в меню приложений; автоматическая сборка и релизы через
  GitHub Actions.
