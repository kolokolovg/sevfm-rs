# Участие в разработке

Спасибо, что хотите помочь! Приветствуется любой вклад: баг-репорты, идеи и
пожелания, улучшения документации, переводы, код.

## Язык

Пишите на русском или английском — как удобнее. Документация проекта — на
русском.

## Прежде чем начать

- **Мелкие правки** (опечатки, документация, небольшие фиксы) — можно сразу
  открывать pull request.
- **Крупные изменения** (новая функциональность, изменение поведения) —
  сначала создайте issue и обсудим. Это экономит и ваше, и наше время.

## Сборка и проверки

Нужен стабильный инструмент Rust ([rustup](https://rustup.rs)).

Системные зависимости на Linux (Debian/Ubuntu):

```sh
sudo apt install libasound2-dev libfontconfig1-dev libfreetype6-dev
```

На Windows — инструментальная цепочка MSVC (та же, что в релизных сборках).

Проверки перед pull request (те же, что выполняет CI):

```sh
cargo build
cargo test
cargo fmt --all --check
cargo clippy --all-targets -- -D warnings
```

## Pull request'ы

1. Fork → ветка от `main` → изменения → PR в `main`.
2. Тесты приветствуются для новой функциональности; для правок документации
   не требуются.
3. Формат коммитов свободный (русский или английский).
4. Сборку релизов и публикацию выполняет мейнтейнер.

## Лицензия

Отправляя вклад, вы соглашаетесь, что он лицензируется на тех же условиях,
что и проект, — **Apache-2.0** (inbound = outbound). CLA подписывать не нужно,
DCO-трейлеры не требуются.
