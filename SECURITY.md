# Политика безопасности

## Поддерживаемые версии

Поддерживается только последний релиз; исправления безопасности в более
старые версии не бэкпортируются.

| Версия              | Поддержка |
| ------------------- | --------- |
| последний релиз 0.1.x | ✅      |
| более ранние        | ❌        |

## Сообщение об уязвимости

**Пожалуйста, не открывайте публичный issue с деталями уязвимости.**

- **GitHub (основной канал):** вкладка *Security* → *Report a vulnerability* —
  приватное сообщение, видимое только мейнтейнерам.
- **GitVerse:** создайте issue с пометкой `[SECURITY]` в заголовке и **без**
  деталей (эксплойт, PoC, шаги воспроизведения) — договоримся о приватном
  канале для дальнейшей переписки.

Пожалуйста, приложите: версию `sevfm`, ОС, шаги воспроизведения или PoC и
оценку влияния.

Отвечаем по мере возможности, обычно в течение 72 часов. Просьба предоставить
разумный срок (до 90 дней) до публичного раскрытия. Программа вознаграждений
за уязвимости не предусмотрена.

## Что не относится к безопасности

- Уязвимости сторонних зависимостей — обычный issue или PR с обновлением
  версии.
- Сбои самого плеера на некорректных или битых аудиопотоках, не влияющие на
  систему, — обычный баг-репорт.

## Проверка релизов

Windows-бинарники подписаны (SignPath Foundation) — цифровая подпись видна на
вкладке «Цифровые подписи» в свойствах файла.
