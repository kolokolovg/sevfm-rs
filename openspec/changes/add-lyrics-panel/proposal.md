# Proposal

## Why

Окно плеера показывает, что играет, но не даёт увидеть слова песни — радиослушателю приходится искать текст вручную в сторонних сервисах. LrcLib доступен из сети пользователя без ключей и покрывает русский репертуар станции на ~90% (живая проба 2026-11-20: 17 из 19 песен разных жанров, включая советскую классику), поэтому текст можно показывать прямо в окне.

## What Changes

- Новый воркер текста песни по образцу воркера обложек (`src/cover.rs`): единственный источник LrcLib (`/api/get`), дисковый кеш с лимитом и LRU-вытеснением, неблокирующая доставка результата в окно.
- Кнопка «Т» в ряду управления рядом с «Играть» и «Стоп»: переключатель панели текста. Неактивна (приглушена), когда текста нет: промах источника, рекламная вставка, поиск ещё не завершён.
- Панель текста справа: окно расширяется 440×560 → 880×560, пока панель открыта. Сплошной текст со прокруткой; в шапке — плашка источника; крестика нет — закрытие только повторным «Т».
- Только plain-текст без синхронизации строки по времени эфира (решение пользователя; проводка позиции не делается).
- Флаг `--clear-cache` очищает оба кеша — обложек и текстов.

## Capabilities

### New Capabilities

- `lyrics`: получение текста играющего трека из LrcLib по artist+title, локальный кеш текстов, состояния доступности (ищется / найден / нет), ограничения сетевых обращений, не-музыка и отказы источника.

### Modified Capabilities

- `player-ui`: требование «Фиксированный размер окна» меняется — размер кадра зависит от состояния панели текста (440×560 ↔ 880×560, пользовательский ресайз по-прежнему запрещён); добавляется требование «Панель текста песни» (кнопка «Т», содержимое панели, поведение при смене трека и остановке).
- `album-art`: требование «Ручная очистка кеша обложек» меняется — `--clear-cache` удаляет также кеш текстов.

## Impact

- Новый модуль `src/lyrics.rs` (источник, кеш, потоковый воркер) — перенос паттернов из `src/cover.rs` (транспорт-trait + тестовый дубль, канал Request/Reply, неблокирующий poll).
- `ui/player-window.slint`: кнопка «Т», панель текста, зависимость ширины окна от состояния панели.
- `src/ui.rs` (`Launch`, `UiState`, `ViewUpdate`), `src/main.rs`: состояние панели и текста в poll-тике, доставка `track_changed` в новый воркер, очистка двух кешей в `--clear-cache`.
- Зависимостей нет новых: HTTP-стек (ureq + rustls) уже в проекте.
- Тесты: юниты с тестовым HTTP-дублем в `src/lyrics.rs` по образцу `FakeHttp`; живой прогон источников — по правилу живых тестов перед ревью.
