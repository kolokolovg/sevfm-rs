# Spec Delta

## ADDED Requirements

### Requirement: Автопрокрутка переполненной трек-строки
Поля трек-строки — исполнитель и название — SHALL показывать строку целиком: при переполнении поля строка SHALL плавно прокатываться туда-обратно в пределах поля, при помещении — стоять по центру без движения. Скорость прокрутки SHALL быть постоянной по расстоянию. При смене трека и изменении ширины окна отображение SHALL перенацеливаться без перезапуска приложения и без многоточия.

#### Scenario: Длинное название в узком окне
- **WHEN** при воспроизведении приходит трек, название которого не помещается в ширину поля при закрытой панели текста
- **THEN** название плавно прокатывается внутри поля туда-обратно, крайние положения показывают начало и конец строки целиком; исполнитель при переполнении прокатывается так же

#### Scenario: Короткая строка
- **WHEN** название и исполнитель помещаются в ширину поля целиком
- **THEN** обе строки стоят по центру без движения — многоточие и прокрутка отсутствуют

#### Scenario: Смена трека во время прокрутки
- **WHEN** во время прокрутки поля приходит метаблок с новым треком
- **THEN** поле перенацеливается на новую строку без перезапуска приложения; короткая строка возвращается в центр покоя

#### Scenario: Расширение при открытой панели текста
- **WHEN** панель текста открыта и окно расширено до 880 px
- **THEN** прокрутка полей трек-строки пересчитывается под новую ширину: помещающиеся строки возвращаются в центр покоя

#### Scenario: Рекламная вставка
- **WHEN** приходит метаблок рекламной вставки
- **THEN** трек-строка показывает заглушку — название станции; если заглушка не помещается, она прокатывается по тем же правилам
