# Change: Автопрокрутка переполненных полей трек-строки (название, исполнитель)

## Why

В узком окне (440 px) длинные названия треков и имена исполнителей обрезаются `overflow: elide` — пользователь не видит конец строки. Поле наименования — главная строка окна («что сейчас в эфире»), обрезка теряет содержимое эфира. Change едет в ближайший релиз вместе с обновлением дерева зависимостей (slint 1.19, url 2.5.9), уже подготовленным в рабочем дереве.

## What Changes

- Новый компонент разметки `MarqueeText` (player-window.slint): контейнер-клип с текстом, который при переполнении (`preferred-width` больше ширины контейнера) плавно прокатывается туда-обратно (ping-pong, `animate x` с `iteration-count: -1; direction: alternate`), в покое остаётся по центру.
- Скорость прокрутки пропорциональна переполнению (~28 px/с), зажата в 3–30 с на проход.
- Поля трек-строки «исполнитель» и «название» переводятся с `Text { overflow: elide }` на `MarqueeText`; условная вставка в layout (`if artist != ""`, `if track-title != ""`) сохраняется как есть.
- Rust-код, зависимости и CI не затрагиваются — правка только в `ui/player-window.slint`.
- Ресайз окна 440→880 и смена трека в эфире перенаправляют анимацию автоматически (проверено компиляцией и при ручной приёмке).
- Находки ручной приёмки 2026-11-22: порог +24px удалён — epsilon создавал мёртвую зону (переполнение меньше порога стояло обрезанным и не скролилось); прокат при любом переполнении, покой переполненной строки до старта анимации — у левого края (центр давал обрезку с обеих сторон). Заголовок панели текста «артист — название» переведён с `overflow: elide` на `wrap: word-wrap` — многоточие прятало хвост длинной связки.

### Modified Capabilities

- `player-ui`: новое требование «Автопрокрутка переполненной трек-строки» — прокат поля при переполнении вместо обрезки, покой по центру при помещении, перенацеливание при смене трека и ресайзе.

## Impact

- `ui/player-window.slint` — новый top-level компонент `MarqueeText`, замена двух `Text` трек-строки (строки 313/322 текущего файла).
- Проверено по исходникам slint 1.19.0: `iteration-count: -1` = бесконечные итерации (properties_animations.rs:227/:318), `direction: alternate` (enums.rs:591), `enabled`-гейт анимации; разметка-прототип собирается компилятором 1.19 без предупреждений (живой минитест в песочнице).
- Поведенческая приёмка (пинг-понг эстетика, рестарт на смене трека, панель текста 440→880) — ручной чек-лист.
