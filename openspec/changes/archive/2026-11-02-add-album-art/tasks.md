## 4. Воркер-поток и логи (lib)

- [x] 4.1 Сервис-поток `cover-service` + `std::sync::mpsc`: воркер дренирует канал до последнего запроса, ответы несут генерацию запроса, устаревшие гасятся при дренировании на стороне потребителя (однопоточность закрывает и ответы, уже лежащие в канале — находка ревью); не-музыка (вставка, трек без исполнителя) — заглушка без обращения к сервисам. Верификация: unit-тесты — медленный запрос вытесняется новым (доставляется только свежий), лежавший в канале ответ гасится инвалидацией, вставка не порождает вызовов транспорта.
- [x] 4.2 Логирование исходов через `say`: находка с источником, попадание кеша, промах всех сервисов, сбой сервиса и мусорный ответ — раздельные формулировки («недоступен» vs «вернул мусор», находка ревью). Верификация: unit-тесты формируют исходы на fake-транспорте; строки лога сверяются ручной головной-проверкой stderr.
