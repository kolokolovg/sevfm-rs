# Proposal

## Why

Спека `radio-player` требует обложку текущего трека (требование «Подгрузка обложки трека»), но после фазы add-player-ui в окне осталась статичная заглушка: цепочка подгрузки обложек была явно отложена в отдельный change (архив add-player-ui, proposal/design). Это последний крупный кусок поведения порта, ещё не реализованный.

## What Changes

- Поиск обложки по исполнителю и названию трека по цепочке публичных сервисов без API-ключа: iTunes Search API → Deezer API → Яндекс.Музыка; первый найденный результат выигрывает, остальные сервисы не опрашиваются.
- Локальный кеш обложек: повторный трек (тот же исполнитель и название) берётся с диска без обращения к сети.
- Отказоустойчивость: сетевой/HTTP-сбой одного сервиса не прерывает цепочку и воспроизведение; промах всех сервисов — изображение-заглушка и запись в лог.
- Окно отображает обложку по правилу видимости трека: трек — обложка (найденная или заглушка), рекламная вставка и «Остановлено» — заглушка, к сервисам за вставку не обращаемся.
- Загрузка обложки асинхронна: не блокирует и не прерывает воспроизведение.

Не входит (Non-goals):

- Синхронизация кеша/очереди обложек с аудио-долотом (метаблоки в очереди тракта) — отдельный change по проекту эфира; здесь обложка обновляется по факту смены трека в окне.
- Выбор обложки пользователем, альтернативные размеры, предзагрузка следующих треков.

## Capabilities

### New Capabilities

- `album-art`: поиск обложки трека по цепочке внешних сервисов (iTunes → Deezer → Яндекс.Музыка) без API-ключа, локальный кеш повторных треков, заглушка при отсутствии, отказоустойчивость и неблокируемость относительно воспроизведения.

### Modified Capabilities

- `player-ui`: требование «Отображение состояния и эфира в окне» расширяется — окно отображает обложку текущего трека с тем же правилом видимости, что и трек-строка (вставка, ожидание метаблока и «Остановлено» — заглушка, а не последняя обложка).

## Impact

- Код: новый модуль lib (HTTP-запросы к сервисам, разбор ответов, кеш), `src/ui.rs` (видимость обложки в `TrackSlot`-модели окна), `src/main.rs` (фоновая подгрузка и запись картинки в окно), `ui/player-window.slint` (свойство-изображение вместо статичного квадрата).
- Зависимости: декодер JPEG/PNG для отображения в Slint (крейт `image` с минимальными фичами) — точный выбор в design.md.
- Внешние сервисы: три публичных HTTPS-эндпоинта; форматы ответов и обязательные заголовки фиксируются в design.md.
- Диск: кеш обложек в пользовательском кеш-каталоге (XDG), без ограничения размера в этом change (политика чистки — вне scope).
- `radio-player`: главное поведение уже описано требованием «Подгрузка обложки трека» — дельта не нужна, реализация закрывает существующее требование.
