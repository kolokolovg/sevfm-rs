# Spec Delta

## MODIFIED Requirements

### Requirement: Отображение состояния и эфира в окне
Окно приложения SHALL отображать статус плеера одной из строк: «Остановлено», «Подключение», «Воспроизведение», «Буферизация», «Переподключение», и название станции из `icy-name` при его наличии. Трек и его обложка SHALL отображаться только при живой сессии; рекламная вставка, ожидание первого метаблока и «Остановлено» дают заглушку: трек-строка — название станции, обложка — изображение-заглушка. Обновление отображения SHALL происходить при каждой смене без перезапуска приложения.

#### Scenario: Первое подключение
- **WHEN** пользователь нажимает «Играть» и сервер отвечает
- **THEN** статус переходит из «Остановлено» через «Подключение» к «Воспроизведению», в окне появляются название станции и текущий трек

#### Scenario: Смена трека в эфире
- **WHEN** во время воспроизведения приходит метаблок с отличным от текущего треком
- **THEN** окно показывает обновлённые исполнителя и название, а по готовности — обложку нового трека

#### Scenario: Рекламная вставка
- **WHEN** во время воспроизведения приходит метаблок рекламной вставки (исполнитель пуст или тип ≠ «М»)
- **THEN** вместо названия вставки окно показывает заглушку — название станции, обложка — изображение-заглушку

#### Scenario: Сырой StreamTitle без JSON
- **WHEN** станция шлёт `StreamTitle` без JSON (вся строка — название трека)
- **THEN** окно показывает название без исполнителя, обложка — изображение-заглушка

#### Scenario: Остановка скрывает трек
- **WHEN** воспроизведение останавливается («Стоп», конец потока или фатальная ошибка сессии)
- **THEN** последний трек не остаётся на экране: трек-строка показывает заглушку — название станции, обложка — изображение-заглушку

#### Scenario: Станция без icy-name
- **WHEN** ответ сервера не содержит `icy-name`
- **THEN** окно работает без названия станции, показывая статус и трек

#### Scenario: Обрыв сети при воспроизведении
- **WHEN** соединение с потоком теряется во время воспроизведения
- **THEN** статус в окне меняется на «Переподключение» или «Буферизация», окно остаётся открытым, текущий трек остаётся видимым
