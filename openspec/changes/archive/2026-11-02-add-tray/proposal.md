# Proposal

## Why

Управление плеером сегодня привязано к окну: единственные точки управления — две кнопки в окне, а закрытие окна немедленно завершает процесс. Классическое поведение десктоп-плеера — сворачивание в системный трей с управлением без окна. Кроме того, KDE-аплет управления плеерами (и любой другой MPRIS-клиент) не видит плеер, потому что приложение не регистрирует MPRIS-сервис на D-Bus.

## What Changes

- Значок в системном трее в UI-режиме на обеих платформах — встроенное API Slint 1.18 `SystemTrayIcon` (feature `system-tray`, входит в дефолтные): tray-компонент и меню объявляются в `.slint`, под капотом на Linux — тот же `ksni` (уже в дереве зависимостей), на Windows — `Shell_NotifyIconW` в winit-насосе Slint. Новых зависимостей для трея нет; платформенно-зависимый код `cfg(target_os)` появляется только у MPRIS. Стек зафиксирован пользователем после сравнения встроенного API с прямыми крейтами ksni/trayicon.
- Меню трея: те же два управления воспроизведением «Играть»/«Стоп» (доступность — как у кнопок окна), «Показать/Скрыть окно», «Выход». Левый клик по значку переключает видимость окна; тултип показывает станцию и статус.
- **BREAKING**: закрытие окна (крестик) больше не завершает процесс — окно скрывается, приложение и воспроизведение продолжают работать из трея. Полный выход — пункт «Выход» в меню трея; SIGINT/SIGTERM сохраняют прежний смысл — штатное завершение с кодом 0.
- MPRIS-сервис `org.mpris.MediaPlayer2.sevfm` на Linux (крейт `mpris-server`, единственная новая зависимость change): PlaybackStatus, команды Play/Stop, метаданные текущего трека и обложка из локального кеша обложек. Перемотка не поддерживается (живой поток): CanSeek=false; «пауза» заявлена и работает как остановка эфира (у виджета KDE своей кнопки «стоп» нет).
- Деградация без среды: если трей недоступен (нет SNI-хоста на Linux, ошибка создания на Windows) или D-Bus отсутствует, приложение SHALL продолжать работу в оконном режиме без краха; без трея закрытие окна возвращается к завершению процесса.
- Headless-режим (`--headless`) не меняется: трей и MPRIS в нём не создаются.
- Новый ресурс: единая иконка приложения `ui/app-icon.png` — герб Севастополя, вырезанный из заглушки обложки; используется и как значок трея, и как иконка окна в заголовке/таскбаре (`Window.icon`).

## Capabilities

### New Capabilities

- `system-tray`: значок в системном трее на Linux и Windows — появление и исчезновение, меню и его доступность, тултип со станцией и статусом, клики по значку, скрытие окна в трей, выход из трея, деградация при недоступном трее.
- `mpris`: D-Bus-сервис MPRIS на Linux — идентичность плеера для внешних клиентов (аплет KDE), соответствие PlaybackStatus состояниям плеера, команды Play/Stop, метаданные трека с обложкой из кеша, заявленные возможности (Can*), деградация при недоступном D-Bus.

### Modified Capabilities

- `player-ui`: Requirement «Завершение работы из окна» — закрытие окна скрывает окно вместо завершения процесса (при живом трее); полный выход переезжает в меню трея; SIGINT/SIGTERM остаются эквивалентом полного завершения; без трея закрытие окна завершает процесс как раньше.
- `radio-player`: Requirement «Отображение состояния» — заключительная фраза о закрытии окна согласуется со скрытием в трей вместо остановки воспроизведения.

## Impact

- Код: `src/main.rs` — создание tray-компонента и MPRIS в UI-режиме, переход на `run_event_loop_until_quit` с `on_close_requested` (скрытие вместо завершения при живом трее, teardown `main.rs:443–470` сохраняется для полного выхода); `ui/player-window.slint` — новый экспортируемый tray-компонент с меню; новый модуль MPRIS (bin) и lib-модель снапшота трея; источник данных — существующий `SessionHandle::tick()` (станция, трек, статус сети).
- Зависимости: единственная новая — `mpris-server` 0.11, linux-gated (выделенный `std::thread` + `zbus::block_on`, без tokio). Трей новых зависимостей не добавляет: ksni 0.3 уже компилируется в дереве через дефолтные фичи slint. В дереве окажутся два мажора zbus (5 через ksni/slint, 6 через mpris-server) — осознанно принято.
- Ресурсы: одна растровая иконка трея `ui/tray-icon.png` (обе платформы, встраивается через `@image-url`).
- Тесты: unit-тесты lib-модели снапшота и маппинга MPRIS; живой тест MPRIS против реальной сессии D-Bus с пропуском без шины; Windows-сборка — гейт `cargo check --target` (платформенного кода трея нет — проверяется сборка целого приложения под Windows).
- Сборка: первые `cfg(target_os = "linux")` в `src/` появятся только вокруг MPRIS; рантайм-тестирование на Windows вне рамок этого change.
