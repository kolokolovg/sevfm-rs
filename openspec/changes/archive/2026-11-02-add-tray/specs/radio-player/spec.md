# Spec Delta

## MODIFIED Requirements

### Requirement: Отображение состояния
Окно приложения SHALL отображать название станции (`icy-name`), текущий статус (Остановлено / Подключение / Воспроизведение / Буферизация / Переподключение) и, при наличии, исполнителя и название трека. При живом трее закрытие окна SHALL скрывать окно, не останавливая воспроизведение и сетевую активность; полный выход — из трея, по сигналу, а при недоступном трее закрытием окна — SHALL полностью останавливать воспроизведение и сетевую активность.

#### Scenario: Показ статуса при обрыве
- **WHEN** соединение с потоком теряется во время воспроизведения
- **THEN** статус в окне меняется на «Переподключение» без закрытия окна

#### Scenario: Закрытие окна во время воспроизведения
- **WHEN** пользователь закрывает окно при идущем воспроизведении и трей жив
- **THEN** окно скрывается, воспроизведение и сетевая активность продолжаются; полный выход из трея останавливает их и завершает работу без зависающих процессов
