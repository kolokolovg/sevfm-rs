# Spec Delta

## Purpose

Значок плеера в системном трее на Linux и Windows: приложение продолжается жить и управляться из трея после скрытия окна, меню трея повторяет управление окна, среда без трея не мешает работе.

## ADDED Requirements

### Requirement: Значок приложения в трее
В UI-режиме приложение SHALL отображать значок в системном трее на протяжении всей работы: на Linux — через протокол StatusNotifierItem, на Windows — через системный трей ОС. В headless-режиме значок SHALL NOT создаваться. Значок SHALL исчезать при полном выходе из приложения.

#### Scenario: Значок при запуске в UI-режиме
- **WHEN** приложение запущено без `--headless`
- **THEN** значок появляется в трее сразу после старта, ещё до нажатия «Играть»

#### Scenario: Headless без значка
- **WHEN** приложение запущено с `--headless`
- **THEN** в системном трее значка нет

#### Scenario: Значок исчезает при выходе
- **WHEN** приложение полностью завершает работу
- **THEN** значок исчезает из трея, «битый» значок не остаётся

### Requirement: Меню трея
Меню значка SHALL предоставлять те же два управления воспроизведением, что и окно — «Играть» и «Стоп» — и SHALL NOT добавлять других управлений воспроизведением (пауза, перемотка). Кроме того, меню SHALL содержать пункты «Показать окно»/«Скрыть окно» и «Выход». Доступность «Играть»/«Стоп» SHALL соответствовать кнопкам окна: «Играть» — только в «Остановлено», «Стоп» — во всех состояниях активной сессии.

#### Scenario: Доступность в «Остановлено»
- **WHEN** плеер в «Остановлено» и открыто меню трея
- **THEN** «Играть» доступен, «Стоп» недоступен

#### Scenario: Доступность при активной сессии
- **WHEN** идёт подключение, воспроизведение, буферизация или переподключение
- **THEN** «Стоп» доступен, «Играть» недоступен

#### Scenario: Запуск из трея
- **WHEN** плеер в «Остановлено» и выбран пункт «Играть»
- **THEN** начинается новая сессия с семантикой кнопки «Играть» окна

#### Scenario: Остановка из трея
- **WHEN** идёт воспроизведение и выбран пункт «Стоп»
- **THEN** звук останавливается в течение секунды, соединение закрывается, статус — «Остановлено»

### Requirement: Тултип значка
Тултип значка SHALL показывать ровно одну строку: при живом музыкальном треке — «исполнитель — название» (сырой `StreamTitle` — только название), без названия станции рядом; при рекламной вставке, в «Остановлено» и до первого метаблока — название станции (до первого соединения, когда станции нет, — название приложения). Тултип SHALL обновляться при каждой смене трека или станции без перезапуска приложения.

#### Scenario: Играющий трек
- **WHEN** играет музыкальный трек
- **THEN** тултип показывает только «исполнитель — название» трека, без названия станции

#### Scenario: Смена трека отражается
- **WHEN** во время воспроизведения приходит метаблок с отличным от текущего треком
- **THEN** тултип показывает нового исполнителя и название

#### Scenario: Рекламная вставка
- **WHEN** приходит метаблок рекламной вставки
- **THEN** тултип показывает название станции, а не название вставки или трека

#### Scenario: Остановлено
- **WHEN** воспроизведение остановлено и станция известна
- **THEN** тултип показывает название станции

#### Scenario: До первого соединения
- **WHEN** плеер запущен, но станция ещё не прислала `icy-name`
- **THEN** тултип показывает название приложения

### Requirement: Видимость окна из трея
Левый клик по значку и пункт меню «Показать окно»/«Скрыть окно» SHALL переключать видимость окна: скрытое окно показывается, видимое — скрывается. Действия трея MUST NOT влиять на воспроизведение.

#### Scenario: Скрытие окна кликом
- **WHEN** окно видимо и пользователь кликает левой кнопкой по значку
- **THEN** окно скрывается, звук продолжает играть, процесс жив

#### Scenario: Возврат окна
- **WHEN** окно скрыто и пользователь кликает по значку или выбирает «Показать окно»
- **THEN** окно возвращается на экран с актуальными статусом, станцией и треком

### Requirement: Полный выход из трея
Пункт «Выход» меню трея SHALL останавливать воспроизведение и сетевую активность и завершать процесс с кодом 0 без зависающих потоков.

#### Scenario: Выход во время воспроизведения
- **WHEN** идёт воспроизведение и выбран пункт «Выход»
- **THEN** звук останавливается, соединение закрывается, процесс завершается с кодом 0

### Requirement: Деградация без среды трея
Если среда трея недоступна — на Linux отсутствует D-Bus-сессия или SNI-хост, на Windows создание значка не удалось — приложение SHALL продолжать работу в оконном режиме без краха и SHALL записать отказ в лог. При недоступном трее закрытие окна завершает процесс.

#### Scenario: Запуск без D-Bus-сессии
- **WHEN** приложение запущено в UI-режиме на Linux без шины D-Bus
- **THEN** окно открывается и работает, в логе запись об отказе трея, закрытие окна завершает процесс

#### Scenario: Ошибка создания значка на Windows
- **WHEN** создание значка в трее Windows завершилось ошибкой
- **THEN** приложение продолжает работать с окном, отказ записан в лог, краха нет
