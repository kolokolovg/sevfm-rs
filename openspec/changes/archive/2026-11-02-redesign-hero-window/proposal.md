# Proposal

## Why

Утверждённый редизайн главного окна (направление «Герой-обложка», согласовано по мокапам всех состояний). Текущая вертикальная компоновка — список независимых элементов со свободным ресайзом — не выражает суть радио-плеера: единственный эфир и то, что в нём звучит прямо сейчас. Свободный ресайз ломает композицию: блоки рассчитаны на фиксированный кадр.

## What Changes

- Окно фиксируется: 440×560, ресайз запрещён (сейчас — свободный).
- Фон клиентской области — обложка текущего трека (`cover`, без искажений) либо заглушка-герб; нижняя треть закрыта градиентом-затемнением для читаемости текста.
- Постоянная строка станции убирается: станция видна только в заголовке окна и как текст заглушки трек-строки (правило видимости `TrackSlot` не меняется).
- Трек-строка становится главной: трек — артист капсом + название крупно; сырой `StreamTitle` — одна строка; заглушка — название станции. Всё по центру.
- Статус получает индикатор: цветная точка (зелёная — «Воспроизведение»; янтарная — «Подключение», «Буферизация», «Переподключение»; серая — «Остановлено»; красная — «Остановлено» при видимой ошибке) рядом с текстом статуса. Фейковых индикаторов уровня звука нет.
- Кнопки «Играть»/«Стоп» — собственный стиль «стеклянных» кнопок поверх фона вместо std-widgets `Button`; гейты доступности и ровно два управления — без изменений.
- Фатальная ошибка сессии — полупрозрачная плашка сообщения над кнопками (правило «до следующего Играть» без изменений).

## Capabilities

### New Capabilities

(нет — поведение окна уже принадлежит player-ui)

### Modified Capabilities

- `player-ui`: меняется требование «Отображение состояния и эфира в окне» (фон-обложка, индикатор состояния, станция без отдельной строки, центровка) и добавляется требование фиксированного размера окна.

## Impact

- `ui/player-window.slint` — полная перекомпоновка `PlayerWindow` (фон, слои, свои кнопки); `PlayerTray` не меняется.
- `src/main.rs` — связка: возможно новое свойство-цвет/вид статуса для точки; набор биндингов в целом сохраняется.
- Трей и MPRIS не затрагиваются: тултип и метаданные берут те же данные (`TrackSlot`), что и сейчас.
- Мокап-договорённости (состояния «Играет», «Реклама», «Остановлено», «Обрыв сети», «Ошибка») — критерий приёмки внешнего вида.
