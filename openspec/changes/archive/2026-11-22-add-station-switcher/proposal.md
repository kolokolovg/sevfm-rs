# Change: Переключатель двух эфиров в главном окне

## Why

Сервер отдаёт два эфира — «Говорит Севастополь» (`https://sevfm.ru:9006/govsev`, дефолт) и «Севастополь FM» (`https://sevfm.ru:9006/stream`, проверен живьём 2026-11-22), — но источник в плеере один: он фиксируется при запуске (`DEFAULT_STREAM_URL` или позиционный URL) и меняется только перезапуском. Пользователь утвердил вариант «сегмент над обложкой» по кликабельным мокапам (`прототипы/sevfm-переключение-станций.html`, вариант A): обе станции видны всегда, переключение одним кликом, обложка не уменьшается.

## What Changes

- Новый компонент разметки `StationSwitcher` (player-window.slint): стеклянная дорожка из двух сегментов с именами эфиров над карточкой обложки; активный эфир выделен светлой заливкой.
- Высота обоих кадров растёт 560→600 (440×600 / 880×600): разведка вёрстки показала, что в живом окне над карточкой 350×350 воздуха нет (верхний край в 15px от верха) — вариант «сегмент в существующий воздух» физически не помещается; утверждённая геометрия A2 (мокап «реальные пропорции») держит обложку 350×350 несжатой и весь текст без наложений.
- Клик по неактивному эфиру: при живой сессии — остановка текущего потока и автоматическое подключение к выбранному (гейт can-play, как у «Играть»); при остановленном плеере — только выбор (выделение меняется, звук не запускается). Повторный клик по активному — без действия.
- Сброс отображения при переключении — по существующим правилам новой сессии: трек-строка, обложка, текст; панель текста живёт по своему текущему жизненному циклу (у нового трека текст есть — панель показывает его, нет — схлопывается, окно возвращается в 440).
- Сегмент присутствует в обоих кадрах — 440 и 880 (левая половина), поведение одинаковое.
- Позиционный URL запуска сохраняется: если он не совпадает ни с одним встроенным эфиром, сегмент стартует без активного выделения; первый клик переключает на встроенный.
- Трей и MPRIS без изменений: «Играть»/«Стоп» и play/pause работают с выбранным эфиром.

### Modified Capabilities

- `radio-player`: команда «Играть» подключается к выбранному эфиру (сейчас требование пинует фиксированный `govsev`); управление дополняется переключателем эфиров (сейчас «ровно два управления»).
- `player-ui`: новое требование «Переключатель эфиров» — размещение, состояния, поведение переключения при живом/остановленном плеере и при открытой панели текста; «Фиксированный размер окна» — высота кадров 560→600; «Управление воспроизведением» — три управления вместо двух (дублирует radio-player в окне).

## Impact

- `ui/player-window.slint` — компонент `StationSwitcher`, вставка между статус-строкой и карточкой обложки.
- `src/ui.rs` — константа списка эфиров (имя + URL), выбранная станция в `UiBinding`.
- `src/main.rs` — обработчик переключения (выбор/стоп/отложенный автозапуск), стартовый индекс по совпадению URL.
- Проверено на мокапах: вертикальный воздух кадра вмещает сегмент ~34px без сжатия обложки; финальная проверка — вёрсткой при apply и ручной приёмкой.
