# Design

## Context

Источник потока сейчас один: `UiBinding.url` фиксируется в `parse_args` (позиционный URL или `DEFAULT_STREAM_URL`, `src/pipeline.rs:84`) и читается в `command_play` при старте сессии (`PlayerSession::start(ui.url.clone(), …)`). Новая сессия стартует только из «Остановлено» — гейт `can-play` отпускает кнопку после завершения воркера (teardown ~100–300 мс), это уже сериализует переключение. Сегмент утверждён по мокапам (вариант A): стеклянная дорожка из двух сегментов над карточкой обложки, активный — светлая заливка.

## Goals / Non-Goals

**Goals:**
- Переключение двух встроенных эфиров одним кликом при живой сессии; выбор без запуска при остановленной.
- Нулевые изменения кадров окна, карточки обложки, трея, MPRIS и жизненного цикла панели текста.

**Non-Goals:**
- Список станций больше двух, меню в трее, переключение из MPRIS — не в этом change.
- Динамический список эфиров с сервера — эфиры зашиты константами.
- Hot-swap потока без остановки (crossfade/двойная сессия) — переключение через полный teardown.

## Decisions

- **Список эфиров — константа в `src/ui.rs`**: `[(«Говорит Севастополь», govsev), («Севастополь FM», stream)]` рядом с `DEFAULT_STREAM_URL`-логикой; один источник правды для разметки (имена) и Rust (URL). Разметке отдаётся `Vec<StationInfo>` + `station-index: int` (-1 — ни одна, кастомный URL запуска).
- **Клик = callback в Rust, не логика в разметке**: `switch-station(int)` обрабатывается в main.rs рядом с `command_play/stop` — переключение меняет `ui.url` и управляет сессией, это уже не «отображение».
- **Семантика переключения — через существующие команды**: при живой сессии `session.stop()` + отложенный автозапуск; при мёртвой — только смена выделения и `ui.url`. Автозапуск НЕ вызывает `command_play` немедленно (гейт can-play ещё закрыт): в `UiBinding` кладётся `pending_station: bool`, существующий poll-такт при открытом гейте выполняет `command_play`. Гонок нет — гейт `is_running()` и так сериализует.
- **Сброс отображения — мгновенно при клике**, не после teardown: трек-строка/обложка/панель гаснут в обработчике (те же вызовы, что в `command_play`: `set_station/artist/track_title/error`, `covers.invalidate`, `lyrics.invalidate`, `panel_open=false`) — пользователь сразу видит, что эфир сменился; статус придёт по ближайшему такту («Остановлено» → «Подключение»).
- **Активный индекс — производное от `ui.url`**: совпадение с константами даёт 0/1, иначе -1; пересчитывается при переключении и при старте. Выделение в разметке — биндинг на `station-index`.
- **Кнопка активного эфира disabled** — повторный клик структурно не может ничего сделать (надёжнее no-op-ветки).
- **Сегмент в разметке один** — он живёт в общей левой колонке, которая при 880 остаётся левой половиной; отдельного размещения для широкого кадра не нужно (у панели свой слот).
- **Титул окна не трогается**: название станции появится, когда новый поток отдаст `icy-name` (существующее поведение).

## Risks / Trade-offs

- [Вертикальный воздух: реальный Slint-лэйаут плотнее мокапа] → РАЗРЕШЕНО выбором пользователя (A2, мокап «реальные пропорции»): карточка 350×350 стоит в 15px от верха, воздуха нет — высота обоих кадров растёт 560→600, сегмент встаёт в верхнюю полосу, карточка сдвигается вниз (фактор центра 0.34→~0.39 высоты), обложка не сжимается и текст не накладывается. Дельта player-ui MODIFIED «Фиксированный размер окна».
- [Пауза тишины между эфирами ~100–300 мс teardown] → осознанно: полный teardown дешевле и надёжнее hot-swap; статус-цепочка «Воспроизведение → Остановлено → Подключение → Воспроизведение» честно её объясняет.
- [Клик во время «Подключения» текущего эфира] → тот же путь (сессия жива → stop + pending), отдельной ветки не нужно.
- [Пользовательский URL запуска теряется при первом клике по сегменту] → осознанно: сегмент — управление встроенными эфирами; вернуть кастомный поток можно только перезапуском (зафиксировано в спеке).
