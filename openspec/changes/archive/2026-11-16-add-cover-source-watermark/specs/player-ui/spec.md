# Spec Delta

## ADDED Requirements

### Requirement: Ватермарк источника обложки
Когда карточка обложки показывает обложку с известным источником, приложение SHALL отображать в правом верхнем углу карточки полупрозрачную плашку с именем источника. Плашка SHALL занимать малую часть карточки у угла, остальная часть обложки SHALL оставаться видимой. Обложка без источника — заглушка (промах поиска, не-музыка, остановка), запись кеша без источника — SHALL отображаться без плашки. При смене обложки плашка SHALL обновляться вместе с ней: имя источника предыдущего трека MUST NOT оставаться на обложке следующего. Ватермарк — элемент окна: за пределами окна (метаданные MPRIS, файлы кеша) обложка SHALL оставаться без ватермарка.

#### Scenario: Обложка с источником
- **WHEN** карточка показывает найденную обложку, полученную от известного сервиса
- **THEN** в правом верхнем углу карточки видна полупрозрачная плашка с именем сервиса («Discogs», «iTunes», «Deezer», «Яндекс.Музыка»)

#### Scenario: Заглушка без плашки
- **WHEN** показана заглушка — промах поиска, вставка, сырой StreamTitle или остановка
- **THEN** плашки на карточке нет

#### Scenario: Обложка из старого кеша
- **WHEN** обложка выдана из кеша без сохранённого источника
- **THEN** обложка показывается без плашки, без ошибки

#### Scenario: Смена трека
- **WHEN** обложка сменилась с трека одного источника на трек другого источника
- **THEN** плашка показывает имя источника новой обложки; между треками плашка не «мигает» именем старого источника поверх новой обложки

#### Scenario: Вне окна ватермарка нет
- **WHEN** внешний потребитель читает обложку через MPRIS `artUrl` или файл кеша
- **THEN** обложка без ватермарка
