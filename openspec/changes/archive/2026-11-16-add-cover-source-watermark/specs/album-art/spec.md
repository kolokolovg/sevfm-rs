# Spec Delta

## ADDED Requirements

### Requirement: Источник обложки доставляется потребителю
Найденная обложка SHALL передаваться потребителю вместе с именем сервиса цепочки, который её вернул. Источник SHALL сохраняться в кеше как часть записи и SHALL восстанавливаться при выдаче обложки из кеша. Отсутствие, нечитаемость или неизвестное значение сохранённого источника SHALL трактоваться как обложка без источника: показ обложки, поиск и воспроизведение MUST NOT затрагиваться, запись в лог не требуется. Удаление записи кеша — вытеснение по лимиту, удаление повреждённой записи, полная очистка `--clear-cache` — SHALL удалять сохранённый источник вместе с записью. Промах поиска источника не имеет; кеш, созданный до появления этого требования, продолжает работать.

#### Scenario: Живой поиск
- **WHEN** трек сменился и обложку вернул один из сервисов цепочки
- **THEN** потребителю передаётся обложка вместе с именем этого сервиса, а не только картинка

#### Scenario: Повторный трек из кеша
- **WHEN** трек уже есть в кеше и обложка выдана из кеша
- **THEN** вместе с обложкой передаётся источник, сохранённый при записи в кеш

#### Scenario: Запись кеша без источника
- **WHEN** запись кеша создана предыдущей версией приложения и источника в ней нет
- **THEN** обложка из кеша передаётся без источника; обращений к сервисам, ошибок и записей в лог нет

#### Scenario: Повреждённый источник
- **WHEN** сохранённый источник не читается или содержит неизвестное значение
- **THEN** обложка передаётся без источника; это не сбой поиска и не сбой кеша

#### Scenario: Вытеснение по лимиту
- **WHEN** запись кеша удалена при превышении лимита размера кеша
- **THEN** сохранённый источник этой записи тоже удаляется; в кеше не остаётся осиротевших источников

#### Scenario: Полная очистка кеша
- **WHEN** кеш обложек очищен флагом `--clear-cache`
- **THEN** удаляются и обложки, и сохранённые источники
