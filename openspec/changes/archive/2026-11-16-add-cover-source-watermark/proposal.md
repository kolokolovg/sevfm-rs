# Proposal

## Why

Обложка находится цепочкой из четырёх сервисов (Discogs → iTunes → Deezer → Яндекс.Музыка), но какой сервис её дал — нигде не видно: имя источника теряется внутри воркера обложек, а кеш хранит только байты картинки. Пользователь хочет видеть источник прямо на обложке — полупрозрачный ватермарк в правом верхнем углу карточки.

## What Changes

- Источник обложки (имя сервиса цепочки) доставляется потребителю вместе с обложкой: расширяется ответ воркера обложек (`CoverReply::Found`) и тип обложки (`CoverImage`).
- Источник переживает кеш: рядом с записью кеша хранится метаданных-файл источника (sidecar); попадание в кеш восстанавливает источник; вытеснение по лимиту, удаление повреждённой записи и `--clear-cache` удаляют его вместе с записью.
- Карточка обложки в окне плеера показывает ватермарк: полупрозрачная плашка с именем источника в правом верхнем углу карточки, только когда обложка настоящая и источник известен. Заглушка, не-музыка (вставка, сырой StreamTitle), промах поиска и обложка из кеша без метаданных источника — без ватермарка.
- Ватермарк — текст (имя сервиса), не логотип: без чужих товарных знаков и дополнительных ассетов.
- MPRIS (`artUrl`) и файлы кеша остаются без ватермарка: он рисуется только в окне как элемент интерфейса, в картинку не запекается.

## Capabilities

### New Capabilities

(нет — расширяются существующие)

### Modified Capabilities

- `album-art`: новое требование «Источник обложки доставляется потребителю» — найденная обложка передаётся вместе с именем сервиса; источник сохраняется в кеше как часть записи и восстанавливается при попадании; отсутствие или повреждение метаданных источника не сбой — обложка показывается без ватермарка; удаление записи кеша удаляет и метаданные.
- `player-ui`: новое требование «Ватермарк источника обложки» — карточка обложки с известным источником показывает полупрозрачную плашку с именем источника в правом верхнем углу; заглушка и обложка без источника — без плашки; сброс обложки на заглушку гасит плашку.

## Impact

- `src/cover.rs` — `CoverImage`/`CoverReply` несут источник; запись/чтение sidecar источника в кеше; вытеснение по лимиту, удаление повреждённой записи и `clear_cover_cache_in` затрагивают sidecar.
- `src/main.rs` — связка: источник обложки в окно, сброс при заглушке (все точки установки заглушки: старт, сброс сессии, не-музыка, промах, авария воркера).
- `ui/player-window.slint` — свойство `cover-source` и плашка-ватермарк поверх карточки обложки.
- Тесты: unit-тесты sidecar (запись/чтение/вытеснение/очистка), существующие тесты кеша расширяются.
- Новых зависимостей нет; формат кеша обратно совместим (старые записи без sidecar продолжают работать — без ватермарка).
