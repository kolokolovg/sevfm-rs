# Design

## Context

Сейчас poll-такт отдаёт artUrl только для музыкального трека с обложкой в кеше (`cached_cover_path` → `file_uri`), остальные состояния — `None` (спека mpris «Без обложки»). Окно в тех же состояниях показывает герб-заглушку — ассет `ui/cover-placeholder.png`, вкомпилированный в бинарник сборкой Slint; файла на диске нет. Каталог кеша — `<XDG_CACHE_HOME|~/.cache>/sevfm/covers` (`cache_dir()`), при `HOME`/XDG без абсолютного пути — `None` и кеш отключён.

## Goals / Non-Goals

**Goals:**
- artUrl зеркалит обложку окна во всех состояниях.
- Нулевые изменения протокола MPRIS и аплетов: это просто другой `file://` URI.

**Non-Goals:**
- Отдача герба через другой канал (D-Bus thumbnail, свой RPC) — не существует.
- Отдельная команда очистки герба — он вне кеша обложек и не чистится `--clear-cache`.

## Decisions

- **Герб на диск один раз при старте**: `include_bytes!("../ui/cover-placeholder.png")` (тот же файл-источник, что у сборки Slint) пишется в `<cache>/sevfm/cover-placeholder.png` — рядом с `covers/`, чтобы `--clear-cache` его не стирал. Файл перезаписывается при каждом старте — самовосстановление после ручных чисток.
- **Отказ — деградация без шума в UX**: каталог не определён или запись не удалась — URI просто не отдаётся (текущее поведение), отказ в лог.
- **Проверка кеша обложки важнее герба**: у музыкального трека сперва `cached_cover_path`; герб — `or_else`-fallback, а не замена: живой трек без обложки в кеше получает герб (окно в этот момент показывает ту же заглушку — согласованность).
- **Тестируемость**: запись и геометрия пути — чистые функции над каталогом (`extract_placeholder_to(path)`, `placeholder_cover_path()` поверх приватного `cache_dir()`); env-зависимая обёртка тонкая, тесты гоняют tempdir.

## Risks / Trade-offs

- [87 КиБ на диск при каждом старте] → несущественно; атомарность не нужна — файл только читается аплетами, обрыв записи чинится следующим стартом.
- [Аплет кеширует URI: файл перезаписан теми же байтами — перечитывания нет] → байты неизменны, кеш аплета всегда валиден.
- [Вставка приходит чаще смены трека — stat/URI на каждый такт] → URI строки кешируются в замыкании poll'а (вычислены при старте), на такте — только клон Option<String>.

## Migration Plan

Новая функция в cover.rs + две строки в poll-такте и старте; откат — revert двух файлов.
