# Spec Delta

## MODIFIED Requirements

### Requirement: Цепочка поиска обложки
При смене музыкального трека приложение SHALL асинхронно искать обложку по исполнителю и названию трека по цепочке публичных внешних сервисов — сначала Discogs, затем iTunes Search API, затем Deezer API, затем Яндекс.Музыка. Обложка первого сервиса, вернувшего результат, SHALL использоваться, остальные сервисы цепочки SHALL не опрашиваться. Сервисы возвращают списки кандидатов — SHALL использоваться первый кандидат с обложкой; поиск Яндекс.Музыки нестрогий (fuzzy) и потому замыкает цепочку.

#### Scenario: Обложка найдена первым сервисом
- **WHEN** для нового трека Discogs вернул обложку релиза
- **THEN** используется обложка Discogs, iTunes, Deezer и Яндекс.Музыка не опрашиваются

#### Scenario: Обложка найдена вторым сервисом
- **WHEN** Discogs не нашёл релиз, а iTunes вернул обложку
- **THEN** используется обложка iTunes, Deezer и Яндекс.Музыка не опрашиваются

#### Scenario: Обложка найдена третьим сервисом
- **WHEN** Discogs и iTunes не нашли трек, а Deezer вернул обложку
- **THEN** используется обложка Deezer, Яндекс.Музыка не опрашивается

#### Scenario: Обложка найдена четвёртым сервисом
- **WHEN** Discogs, iTunes и Deezer не нашли трек (в том числе из-за отличий в написании), а Яндекс.Музыка по нестрогому поиску вернула список кандидатов
- **THEN** используется обложка первого кандидата списка — верх ранжирования Яндекса

#### Scenario: Несколько кандидатов у сервиса
- **WHEN** любой сервис вернул список из нескольких треков с обложками
- **THEN** используется обложка первого кандидата списка (верх ранжирования сервиса)

## ADDED Requirements

### Requirement: Необязательный токен Discogs
Токен пользователя для API Discogs SHALL браться из переменной окружения `SEVFM_DISCOGS_TOKEN`. Заданная непустая переменная SHALL применяться в заголовках запросов к API Discogs; не заданная или пустая — SHALL трактоваться как анонимный доступ. Отклонение запросов Discogs SHALL трактоваться как сбой сервиса: цепочка переходит к следующему сервису без вреда воспроизведению.

#### Scenario: Токен задан
- **WHEN** переменная `SEVFM_DISCOGS_TOKEN` содержит непустое значение и трек сменился
- **THEN** запросы к API Discogs выполняются с токеном в заголовке, в логе — только факт использования токена

#### Scenario: Токен не задан или пуст
- **WHEN** переменная `SEVFM_DISCOGS_TOKEN` не задана или пуста
- **THEN** запросы к API Discogs выполняются анонимно, поиск идёт по общей цепочке

#### Scenario: Анонимный доступ отклонён
- **WHEN** API Discogs отклоняет запросы без токена (анонимный доступ отозван)
- **THEN** Discogs трактуется как сбойный сервис, цепочка переходит к iTunes, в логе — сбой с подсказкой задать токен, воспроизведение не прерывается

### Requirement: Скрытность токена Discogs
Значение токена SHALL NOT попадать в лог и SHALL NOT встраиваться в поставляемое приложение.

#### Scenario: Токен не утекает в диагностику
- **WHEN** при любом исходе поиска обложки записывается лог
- **THEN** значение `SEVFM_DISCOGS_TOKEN` отсутствует в записях лога
