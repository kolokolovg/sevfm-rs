# Design

## Context

Тракт фазы 1 (архив `2026-11-02-add-audio-pipeline`): `net.rs::open_stream` отправляет GET **без** `Icy-MetaData` и возвращает только `Box<dyn Read>` — заголовки ответа выбрасываются; `pump` пишет сырые байты сокета в кольцевой буфер; `pipeline.rs` декодирует MP3 из буфера; `main.rs` опрашивает `SharedNetStatus` в цикле статусов с дедупликацией печати (`POLL_INTERVAL`). Мусорный бюджет (`GarbageBudget`) наращивается байтами, записанными в буфер. Продуктовая спека `radio-player` уже фиксирует правила `StreamTitle` (JSON/строка/вставки) — дельта `icy-metadata` переносит их в контракт среза «тракт+CLI» без изменений.

## Goals / Non-Goals

**Goals:**
- Метаданные вырезаются из потока **до буфера**: декодер и `pipeline.rs` не меняются вовсе.
- Кадрирование устойчиво к реалиям сокета: блоки на границах чанков чтения, обрыв посреди блока, мусорные блоки.
- Текущий трек и станция доступны CLI через тот же паттерн опроса, что и `NetStatus`.

**Non-Goals:**
- Обложки (iTunes/Deezer/Яндекс) и окно Slint — отдельные change'ы; здесь потребитель один — stderr.
- ICYv2 (Ogg-комментарии), перекодировка `icy-name` из Latin-1.
- Переопределение `icy-metaint` через CLI.

## Decisions

### D1: Договорённость в `open_stream` — заголовки наружу

`open_stream` отправляет запрос метаданных (`Icy-MetaData: 1`) и возвращает не голый `Read`, а структуру: `OpenedStream { body: Box<dyn Read + Send + Sync>, metaint: Option<u32>, icy_name: Option<String> }`. Заголовки читаются на каждом подключении — переподключение переустанавливает договорённость само собой (сценарий спеки). `icy-metaint`: отсутствует, нечисловой или 0 → `None` (сервер без ICY — легитимный режим чистого MP3, не ошибка). `ureq` отдаёт значения заголовков строками; поиск регистронезависимый.

### D2: Кадрировщик `IcyFramer` в reader-потоке, до `buffer.write`

Конечный автомат в `src/icy.rs`: `IcyFramer::new(metaint)` + `push(&[u8]) -> FramerOutput`, где выход — последовательность аудиоучастков и завершённых метаблоков. Состояния: `Audio { until_metaint }` → байт длины → `Meta { remaining }` → снова `Audio`. Неполный метаблок (граница чанка) буферизуется внутри фреймера до `1 + 255*16` байтов — аллокация одна на соединение, вне горячего цикла. Обрыв посреди блока: фреймер живёт в рамках одного `pump` (одно соединение) — недособранный блок умирает вместе с ним, нового соединения кадрирование начинается с заголовков заново.

Инвариант: `sum(audio) + sum(1 + 16*len_byte) == входные байты` — основа property-based-теста.

В `pump`: `chunk[..n]` → фреймер → аудиоучастки → `buffer.write` (по участкам; возможен >1 write на чтение — допустимо, `write` блокирующий), метаблоки → `icy::parse_meta` → слот (D3). `IcyFramer` с `metaint == None` — тождественный проход (нулевая цена пути «сервер без ICY»).

### D3: Парсинг `StreamTitle` — `serde_json`, вставки — правила спеки

`icy::parse_meta(&[u8]) -> Option<TrackInfo>`: поиск `StreamTitle='…';` префиксно-байтовым сканом (значение — сырые байты до закрывающей `'`, `''` — экранированная кавычка), UTF-8 c `from_utf8_lossy`. Затем `serde_json::from_str` в структуру `{ artist: Option<String>, name: Option<String>, r#type: Option<String> }`: успех и оба поля непустые/`type == "М"` → `TrackInfo { artist: Some(..), title: name }`; успех, но `artist` пуст или `type ≠ "М"` → вставка: `artist: None, title: name` (если и `name` нет — блок игнорируется); провал JSON → вся строка как название (`artist: None`). Валидный JSON-не-объект (скаляр/массив) — тоже сырая строка как название (по спеке icy-metadata); игнор — только JSON-объект без `name`. `TrackInfo` хранит уже разобранное — правила вставок не протекают в CLI.

Выбор `serde_json` (а не ручной извлекатель ключей): JSON недоверенный и обрезанный (сценарий спеки) — самописный сканер с экранированием/юникодом повторяет баг-поверхность библиотеки; `default-features = false` — без pull-дерева форматов. std JSON не умеет — крейт обоснован.

Санитизация не дублируется: единственный путь значения наружу — `say()` (lib.rs уже заменяет управляющие байты).

### D4: Бюджеты — аудиобайты и сырые байты разведены

Мусорный бюджет наращивается **аудиобайтами после фреймера** (метаблоки — не мусор декодера: он их не видит). Окно минимальной скорости — **сырыми байтами сокета** (метаблоки — тоже прогресс сервера). Комментариями в `pump` зафиксировать асимметрию.

Дополнительно (meta-flood, защита от CPU-DoS): `icy-metaint` вне диапазона 512..64 КиБ трактуется как «без ICY» (метаблоки пойдут в аудиопуть — мусорный бюджет переподключит); плюс лимит метабайтов окна `META_RATE_LIMIT` = 64 КиБ за `MIN_RATE_WINDOW` (10 с) в `pump` — превышение закрывает соединение, счётчик живёт в рамках одного `pump`.

### D5: Слот `NowPlaying` — паттерн `NetStatus`, печать в `main`

`Arc<Mutex<NowPlaying>>`, `NowPlaying { station: Option<String>, track: Option<TrackInfo> }`; пишет только reader-поток, читает `main` в существующих циклах опроса (стартовом и живом) с дедупликацией: станция печатается при первом появлении (`станция: …`), трек — при изменении (`сейчас в эфире: АРТИСТ — НАЗВАНИЕ` / `сейчас в эфире: НАЗВАНИЕ`). Reader сам ничего про трек не печатает — единая точка пользовательского вывода, переиспользуется будущим UI без изменений тракта.

### D6: Зависимости

`serde_json` (runtime, `default-features = false`), `proptest` (dev; скилл называет ICY-метаблоки целевым объектом PBT). Оба — с комментарием-обоснованием в `Cargo.toml`; `Cargo.lock` закоммитить вместе.

### D7: Тесты

- Юнит `icy.rs` (таблично, на реальных байтах): валидный блок с JSON; `StreamTitle='Реклама'`; обрезанный JSON; вставка `type:"Д"`/пустой `artist`; блок без `StreamTitle`; `''`-экранирование; блочный размер-байт 0.
- proptest: (а) для произвольных аудиобайтов и метаблоков `IcyFramer` восстанавливает аудио в точности и выдаёт блоки (инвариант D2), включая разрезы на чанки в произвольных границах; (б) `parse_meta` на произвольных байтах не паникует.
- Мок-сервер (`tests/common`): новый воркер — фикстура + метаблоки каждые `metaint` байтов, сценарии «трек меняется посреди потока» и «сервер без ICY». Интеграционные (`tests/net_reader.rs`): байты, дошедшие до буфера, байт-в-байт равны фикстуре (чистота аудиопути); слот трека меняется по сценарным блокам; переподключение сохраняет кадрирование; отсутствие `icy-metaint` — воспроизведение без трека.

## Risks / Trade-offs

- [Сервер лжётся о `icy-metaint` (дрейф интервала)] → метаблоки попадают в аудиопуть → ошибки декодера → мусорный бюджет (256 КиБ) переподключает; самовосстановление тракта фазы 1, без нового механизма.
- [`icy-name` в Latin-1 у отдельных станций] → ureq отдаёт строку как есть: покажется искажённо; не лечим (Non-Goal), трек не страдает.
- [Станция шлёт `StreamTitle` без кавычек/с мусором] → `parse_meta` вернёт None — трек не обновляется; диагностика не плодится (следующий блок исправит).
- [Разрез аудиочанка фреймером на несколько `buffer.write`] → чуть больше вызовов на чтение; `write` блокирующий, backpressure сохраняется.

## Migration Plan

`open_stream` меняет возвращаемый тип — правка локальна (вызов один, в `reader_loop`). Откат — вернуть `Box<dyn Read>` и выбросить заголовки; фреймер с `metaint == None` уже эквивалентен текущему поведению.
